# Starfield

Starfield produces an animation of continually moving through a field of stars.  
Start date: 2019-09-03  

## Demo

![Sample screenshot](Picture1.png)

## Dependencies

- [Processing 4.0 beta 1](https://processing.org/download)

## Installation

Open any of the `*.pde` files with Processing (IDE).

## Usage

Launch the program using Processing (IDE).
